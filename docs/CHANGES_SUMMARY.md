## H. 编译错误修复记录（CI 报错 → 根因）

| # | 报错 | 根因 | 版本 |
|---|---|---|---|
| 1 | `Unresolved reference 'StateFlow'` | 少导入 | 修复批次 1 |
| 2 | `Unresolved reference 'prefs'` | 重构 `write()` 后残留旧代码 | 1 |
| 3 | `Function0<String> expected` | `ifEmpty("空")` 要的是 lambda | 1 |
| 4 | `Bitmap? vs Nothing?` | `suspendCancellableCoroutine` 推断不出类型 | 1 |
| 5 | `GroupCard(...) { } { }` | Kotlin 不允许双尾随 lambda | 1 |
| 6 | `'return' is prohibited here` | `init {}` 块里不能 return，抽成 `initialize()` | v1.5.2 |
| 7 | `Unresolved reference 'appName失败'` | `$appName失败` 中文被并入变量名 → 改 `${appName}` | v1.6.0 |
| 8 | `Unresolved reference 'matchedName发'` | 同上 | v1.7.1 |
| 9 | `newProcess ... is private` | Shizuku 13.x API 变更 → 撤依赖 | v1.7.1 |
| 10 | 单元测试空指针风险 | `match!!` 之后又用可空变量（无智能转换） | 修复批次 1 |

## I. 架构上新增的东西

- **多动作协议 v3**：一句话最多 5 个动作，`{"actions":[...]}`，兼容旧单动作格式
- **可插拔云端适配器**：豆包 / 通义 / DeepSeek / 书生 / OpenAI 兼容 / 私有
- **严格 JSON 清洗**：去代码围栏、取最外层对象、同义词归一、字段别名
- **引擎抽象**：`WakeEngine / AsrEngine / SpeakEngine / VadEngine`，缺模型自动降级不崩溃
- **导航候选桥**：`PlaceChoiceBridge` 让服务和界面双向通信（点选 / 语音并行）
- **模型管理**：应用内下载（tar.bz2 + 直链）、导入、删除、完整性校验
- **文档**：PROTOCOL / MODELS / BUILD / KEYS / PERMISSIONS / VERIFICATION / HANDOVER
