## 二、已经踩过并修好的坑（别重复踩）

| 现象 | 根因 | 现状 |
|---|---|---|
| 悬浮球看不到 | 窗口在子线程创建 | 已改为主线程 Handler |
| 识别一直"没听清" | 模型文件损坏（Protobuf parsing failed） | 下载加了三道校验 + 删除重下按钮 |
| 唤醒失效 | 自定义关键词写了中文，建流失败 | 自动回退模型自带词表 + 中文警告 |
| 云端一直无法识别 | 书生返回"Thinking Process"被 max_tokens 截断 | 严格重试（第二次只要 JSON）+ max_tokens 512/768 |
| 云端全超时 | 未限输出长度，模型长篇大论 | 已加 max_tokens + 超时默认 30s |
| 微信进不去聊天 | 按文本找结果命中了搜索框自己 | 排除搜索框 + 必须等到不同的输入框 |
| 关闭应用无效 | killBackgroundProcesses 只能杀后台 | 回桌面→kill→应用详情强行停止，三级兜底 |
| 编译错误（多次） | `$变量名` 紧跟中文被当成变量名 | 全工程已扫描修正，写字符串务必用 `${var}` |
