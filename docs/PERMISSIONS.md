# 权限开启说明

应用**不会**也无法自动开启无障碍、悬浮窗、电池优化白名单——这些都只能由你手动开。

## 必须开

| 权限 | 在哪开 | 不开会怎样 |
|---|---|---|
| 录音（运行时） | 首次启动弹窗 | 唤醒和识别都用不了 |
| 通知（Android 13+） | 首次启动弹窗 | 前台服务没有常驻通知，容易被系统杀 |

## 按需开

### 无障碍服务（微信发送、截屏、部分应用控制）

1. 设置 → 系统与调试 → 或在「技能管理」点「去开启无障碍服务」
2. 系统设置 → 无障碍 → 已下载的服务 → **本地语音助手 · 指令执行** → 开启
3. 回来确认首页「无障碍服务」显示已开启

> 只有你主动点了开启才会生效；应用退出该页面后不会自动开启，也不会偷偷开启。

### 悬浮窗（悬浮小球 + Android 14 后台启动豁免）

1. 设置 → 系统与调试 → 悬浮窗权限
2. 打开「显示在其他应用上层」
3. 回到设置打开「悬浮小球」开关

### 电池优化 / 自启动（国产 ROM 必做）

- 设置 → 系统与调试 → 电池优化 → 选择「不限制」或加入白名单
- 品牌自带的自启动管理：小米「自启动」、华为「应用启动管理」、OPPO/vivo「自启动」，
  需要给本应用允许自启动与后台活动

### 开机自启

- 设置 → 系统与调试 → 打开「开机自启」
- 注意：**Android 14 起，麦克风类型的前台服务不允许从开机广播直接启动**，
  只有已授予悬浮窗权限的应用等少数情况例外。所以：
  - 悬浮窗权限 + 开机自启都开 → 大概率能自启成功
  - 否则自启会静默失败，需要你手动打开一次 App（不会反复弹窗骚扰）

## 不会申请的权限

- 存储读写：截屏走 MediaStore，模型与日志在应用私有目录，不需要存储权限
- 通讯录、短信、定位：完全不需要
- `QUERY_ALL_PACKAGES` 只用于「打开某某应用」时按应用名匹配，不上传任何应用列表
